Westcoast Education - Steg 2

Det här är min inlämningsuppgift där jag har gjort en desktop applikation med C# och Avalonia.

Programmet är till för att kunna hantera kurser, studenter och lärare på Westcoast Education.


Databasen----------------------------

Programmet använder RestDB.io och behöver en API nyckel för att kunna hämta och spara information.

Nyckeln ska läggas in som en miljövariabel med namnet RESTDB_API_KEY.

Jag har inte lagt API nyckeln direkt i koden för säkerhetens skull
